# Definition of done

A feature is complete only when it works in the integrated game.

## Required evidence

- Code compiles with the team-approved Unity 6.6 editor patch.
- Relevant automated tests pass.
- The feature is exercised in the intended Unity scene.
- Player-facing text is English.
- The feature remains understandable with audio muted.
- Save and load behavior is verified when the feature changes persistent state.
- Visual behavior is checked in the Unity Editor or a Windows x64 build; compilation alone is not visual evidence.
- Manual verification steps and remaining risks are documented.

## Task report

Every completed task reports:

1. Files created or modified.
2. Implementation details.
3. Tests actually executed.
4. Test results.
5. Unity Editor actions required.
6. Integration risks.
7. Remaining issues.
8. Suggested Git commit.
