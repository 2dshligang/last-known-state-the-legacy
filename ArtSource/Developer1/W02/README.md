# W02 URP import and inspection

Base: accepted W01, merge commit `aa2258b`. Editor: Unity 6000.6.9f1.
Render pipeline: URP 17.6.0. World and art ownership: Developer 1.

## Inspect in Unity

Open `Assets/_Game/Scenes/W02AssetInspection.unity` and select the Game view
for the saved inspection camera. The orange cube measures one meter on each
axis. The scene contains one instance of each W01 model and is outside the
player build scene list. See the inspected [Unity capture](unity-inspection.png).

`LKS > World > Create W02 Asset Inspection` fills in missing W02 assets. It
keeps existing materials, prefabs and scene files so that a repeat run preserves
manual edits and references. Save any untitled editor scene before generating
the inspection scene interactively. When the scene already exists, open it from
the Project window.

| Rounded rock | 0.68 / 0.42 / 0.54 | One approximate box |

Each wrapper under `Assets/_Game/Prefabs/W02` has `Visual`, `Collision` and
`Anchors` children. The imported model lives under `Visual`. Use the wrapper
root for positioning. Preserve the imported FBX root conversion when replacing a
mesh. The upright wall spans X from -4 to 0, Y from 0 to 3 and Z from -0.1 to
0.1 relative to the wrapper. Its `SnapStart` is at the origin and `SnapEnd`
is at (-4, 0, 0). `InspectPoint` is a geometric attachment point.

Model import uses one unit per meter, retains the wall root axis conversion,
imports FBX normals, calculates OBJ normals and MikkTSpace tangents, and
generates secondary UVs. Colliders belong to the wrappers, which keeps
physics independent of model reimport. The rules are limited to W01 models
marked `LKS.W01.OriginalPlaceholder` and the three explicit W02 texture paths.
Stable asset GUIDs are preserved. W01 hash records were updated for the
intentional ModelImporter serialization changes. Unity can add whitespace to
empty scalar values when reserializing YAML locally. The repository stores
the canonical form without trailing whitespace.

W03 can use the wrappers as reference modules and preserve separate collision
and visual children. Use S01 API 1.0 for future gameplay bindings. W02 only
defines art names and attachment points.

## Texture inventory

All three solar-panel images are original 256 x 256 procedural inspection
textures generated by the editor tool. Base color imports as sRGB, the
tangent-space normal image uses Normal Map import, and the metallic/smoothness
texture imports as linear data with alpha preserved. URP Lit's metallic map
stores metallic in red and smoothness in alpha, with code values computed as
`255 - roughness`. Graybox roughness values 102 and 54 yield alpha values 153
and 201. The material's smoothness multiplier is 0.6 to keep the cell pattern
readable under the inspection lights.

Missing maps for the wall, floor, rack, bench, and all three rocks: base color,
normal, metallic and roughness. These models use constant URP Lit material
values. The solar panel has the three inspection maps described above. Final
surface textures and optional occlusion maps are deferred to art production.
No downloaded assets are part of W02.

## Reproduce the round trip

Run the following in PowerShell from an isolated checkout with Unity closed.
Choose new output paths for the FBX and PNG.

```powershell
$blender = 'C:\Program Files\Blender Foundation\Blender 5.3\blender.exe'
$unity = 'C:\unity\6000.6.9f1\Editor\Unity.exe'
$project = (Get-Location).Path
$env:LKS_W02_WALL_REVISION = Join-Path $env:TEMP 'lks-w02-wall-revision.fbx'
& $blender --background --factory-startup --python-exit-code 1 --python ArtSource/Developer1/W02/export_wall_revision.py -- $env:LKS_W02_WALL_REVISION
$arguments = @('-batchmode', '-nographics', '-quit', '-projectPath', ('"' + $project + '"'), '-executeMethod', 'LKS.Editor.World.W02Verification.Verify', '-logFile', 'w02-verify.log')
$run = Start-Process -FilePath $unity -ArgumentList $arguments -PassThru -Wait -WindowStyle Hidden
if ($run.ExitCode -ne 0) { throw 'W02 verification failed. See w02-verify.log.' }
Remove-Item Env:LKS_W02_WALL_REVISION
```

The revision script loads the accepted Blender 5.3.0 source and reuses the
W01 export settings: selected mesh, scale 1, unit scaling with
`FBX_SCALE_UNITS`, forward -Z, up Y, face normals and triangulation.
It changes UV0 only. The verifier first runs two repeated imports and
two generation passes, then temporarily installs the revision at the same
FBX path. It checks that the UVs changed in the nested model, references
and colliders stayed stable, and original FBX bytes and UVs are restored.
An abrupt process termination could interrupt the restore, so use a
disposable checkout. Run without `LKS_W02_WALL_REVISION` for repeated import
checks without exchanging source bytes.

To capture the scene, set `LKS_W02_PREVIEW` to a new PNG path and run
`LKS.Editor.World.W02Verification.RenderPreview` in batch mode with
`-force-d3d11` in place of `-nographics`. The final capture was inspected
after reducing the panel glare from the first render.

## Verification record

- Clean import and compilation in Unity 6000.6.9f1.
- Two forced reimports and repeat generation passes. Asset snapshots, prefab
  and mesh reference identities, materials, attachment points and colliders
  were identical after each pass.
- Same-path Blender revision reached Unity. Measured wall geometry and
  fitted collider matched within 1 mm. A ray hit the wall at the expected
  distance, a ray passed through the bench opening, and the original FBX
  was restored.
- Validated UV0, UV2, normals, texture color spaces, packed values and
  bindings. Rendered and visually inspected the saved scene through URP D3D11.
- All four project EditMode tests passed with zero failures or skips.
- The scene is for Editor inspection. A player build and PlayMode suite were
  outside this verification.
